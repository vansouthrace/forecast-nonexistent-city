A [make.fun](https://make.fun/bounty/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c) entry for "Deadpan Forecasts for Cities That Do Not Exist": one absurd-but-believable weather line for an invented city, written to sound like a straight-faced TV meteorologist reading it off the map.

> In Brambleford, thick fog this morning, highs of 19, and scattered showers falling politely upward by mid-afternoon.

The forecast is 116 characters, inside the 160-character gate, and it was picked from five candidates for the sharpest deadpan twist: the rain does not just fall, it falls *upward* — and politely, as if it had manners and a permit.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# writes out/entry.txt
```
